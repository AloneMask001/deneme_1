# Pazaryeri logoları

Resmî logo dosyalarını buraya mağaza anahtarıyla koyun:

    trendyol.svg      (ya da .png / .webp)
    hepsiburada.svg

`npm run build` çalıştırıldığında satın alma butonları otomatik olarak
gerçek logoyu kullanır; dosya yoksa mağaza adı marka renginde yazı
biçiminde gösterilir.

Logoları pazaryerlerinin resmî marka/iş ortağı sayfalarından indirin:
- Trendyol satıcı paneli → Mağaza / Marka varlıkları
- Hepsiburada iş ortağı kaynakları

Öneri: şeffaf zeminli SVG, yatay (wordmark) versiyon.
